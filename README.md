# Pinly Android app project

This folder contains the Pinly app source code.

## Features in this starter version
- Pinterest-style two-column photo feed
- Search and category filters
- Save and unsave ideas (saved on this device)
- Saved ideas page
- Share a photo link
- Simple profile page

## Important
This is source code, **not an installable APK**. Build an APK with Expo EAS after uploading the project files to GitHub and opening the repository in a cloud development environment.

Photos load from the internet, so an internet connection is required.
